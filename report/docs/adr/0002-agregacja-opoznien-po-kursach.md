# Agregacja opóźnień po kursach

Kolor zbiorczy odcinka wynika z mediany reprezentatywnych wartości opóźnienia poszczególnych kursów, z równą wagą każdego kursu; szczegóły pokazują również maksimum i liczbę kursów. Bezpośrednia agregacja wszystkich zapisów źródłowych dawałaby większy wpływ przejazdom z większą liczbą obserwacji, w tym powtórzeń z pamięci podręcznej, podczas gdy celem jest opis typowego kursu. Mediana może ukryć rzadkie duże opóźnienia, dlatego zachowujemy informację o maksimum oraz możliwość przejścia do danych pojedynczego kursu.
