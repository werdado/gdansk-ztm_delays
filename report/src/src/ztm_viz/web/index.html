Raport wymaga udostępnienia przez HTTP. Otwarcie pliku bezpośrednio z dysku (file://) nie działa. Uruchom uv run ztm-viz serve --report <katalog raportu> albo udostępnij katalog dowolnym serwerem plików statycznych.

Opóźnienia komunikacji miejskiej w Gdańsku

Dni

zielony: bez opóźnienia (≤ 0, także przed czasem) pomarańczowy: do 5 min czerwony: ponad 5 min szary: brak danych

Mapa

Podkład mapy jest niedostępny; trasy i wykres działają normalnie.

Opóźnienie wzdłuż trasy

Typowe opóźnienie (mediana kursów) przy końcu każdego odcinka. Kliknij odcinek, aby zobaczyć szczegóły.

Szczegóły odcinka

Wybierz odcinek na mapie lub wykresie.

Jakość i pochodzenie danych
Dane: archiwum ZTM Gdańsk (GPS). Rozkład jazdy jest tylko wskazówką dla tras i nazw. Opóźnienie przy końcu odcinka nie jest pomiarem dokładnego czasu przyjazdu.
